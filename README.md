## 作品について

唐宋八家文の原文（訓点付き）。沈徳潜の『唐宋八家文読本』により、韓愈・柳宗元（上巻）、欧陽修・蘇洵・蘇軾（中巻）、蘇軾・蘇轍・曾鞏・王安石（下巻）の文を収める。有朋堂書店が『漢文叢書』の一冊として出した、原文に訓点を付けた版。昭和 3 年（1928 年）刊。各巻の例言・目次は入れていない。

## 本文の作り方

国立国会図書館デジタルコレクション（インターネット公開）の全文テキスト（OCR）をそのまま収めた。1 段落が底本の 1 コマ（見開き）。校正はしていないので、振り仮名や柱の混じり、読み違いが残る。
